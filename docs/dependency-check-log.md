# 検査の記録

依存規則と飛ばし禁止の検査(`make check-deps`)が、違反を検出したときの記録です。検査の手順が、日時と、検査の出力を、自動で追記します([ADR-008](adr/ADR-008-observation-records.md)「取り漏らしを防ぐ手段」)。

- 手で書き換えない。違反を直した後も、記録は残す。
- 規則に違反する見本に対する検査(`make check-deps-selftest`)は、記録しない。
- スライスの完了時に、この記録にある違反を、[観察記録](observations.md)の都度の記録と突き合わせる。同じ違反を、直すまでに繰り返し検出した場合は、1件と数える。
- 検査の道具が、違反のほかの理由(設定の誤り、型検査の失敗など)で失敗した場合も、記録される。違反として数えるかどうかは、出力で判断する。
